# Monetization framework — player-respectful starting point

This prototype has no commerce or advertising SDKs. The following is a product framework, not an implementation instruction.

## Principles

- The core campaign must remain completable without spending.
- Never sell a move after a loss with manipulative language or unclear pricing.
- Price and reward boosters consistently; show odds when rewards are random.
- Make consent, restore purchases, parental controls, support, privacy information, and an ad-free option easy to find.

## Suggested offers

| Moment | Offer | Guardrail |
|---|---|---|
| Early progression | Optional starter bundle: cosmetic kingdom skin + gems + boosters | Never needed to clear levels |
| Lives empty | Opt-in rewarded ad for one life, capped at 3/day | No forced interstitial in a level |
| Daily return | Free streak chest / short quest | No paid streak protection pressure |
| Established players | Seasonal cosmetic pass with transparent reward path | All gameplay power available through play |
| Convenience | One-time ad-free purchase | Clearly described, permanent restoration |

## Metrics to validate before scaling

Track tutorial completion, day-1/day-7 retention, level failure rate, average moves left on wins, voluntary booster use, and ad opt-in rate. Review by level segment rather than using a single blended number. Do not launch paid acquisition until retention and tutorial comprehension show organic promise.

## Compliance checkpoint

Before shipping, use regional legal review for privacy, age rating, consent, disclosures, refunds, platform rules, and any randomized reward mechanics. Build analytics so it can operate with minimal data collection and honor deletion/consent preferences.
