# Art and audio placeholders

The runnable prototype uses Unicode emoji as legal, portable placeholders for characters, gems, and buildings. Replace them with original production assets here.

Suggested subdirectories:

```
characters/    transparent PNG/WebP character portraits and in-game figures
gems/          six gem sprites plus special-gem variants
kingdom/       building and environment art
ui/            buttons, badges, map nodes, particles
audio/         music, UI cues, match, cascade, and victory sounds
```

Keep an asset-source/license record with every production file.
